
# Booksy — Frontend Setup

Ghid rapid pentru configurarea și rularea frontend-ului aplicației **Booksy**.

---

## 1 Instalează dependențele 

```bash
npm i
```

---

## 2 Creeaza fisierul `.env` la root-ul frontend-ului(booksy_front)

```bash
#continut fisier
VITE_API_BASE_URL=http://localhost:8000/api
VITE_APP_NAME=Booksy
```


## 3 Ruleaza

```bash
npm run dev
```
